# Atropos v1.4.0 — Integration Contract (internal)

Wave-2 wiring spec for the v1.4 release. All new core modules are built by
Wave-1 agents in parallel; this document is the exact contract for wiring
them into `core/dashboard.py`, `atropos` CLI, `core/tui.py`, `core/console.py`,
`dashboard/index.html`, `dashboard/chat.html`, `dashboard/sw.js`.

## 10. Hard rules (from brief)

- stdlib only; no new deps.
- docstrings on every public fn; no TODO/FIXME; no dead imports.
- console/chat whitelist-only (validators).
- 3 deployment modes everywhere; atropos-only never overwritten; hash-guard
  conflicts ask (identity/configs).
- routers stay nain/omni/local; product name Atropos; Moirai = labels only.
- Farsi correct UTF-8 + RTL.
- No plaintext secrets (mcp env refs, settings masking).
