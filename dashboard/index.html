Self-Healing pipeline

Runs doctor --fix → patch verify (re-apply if broken) → watch checks. One click fixes most issues after an update or restart.

Press "Run Self-Heal" to start.

How it works

  1. Doctor — checks 7 health signals
  2. Patches — verifies 12 hacks, re-applies broken ones
  3. Watch — disk, logs, transient state
  4. Everything runs inside one request. Failures show inline.
Schedule: add atropos watch --daemon to your start command for continuous healing.

Telegram alerting

Sends a Telegram message when disk is ≥80%, doctor fails, router is down, or patches fail. Configure bot token + chat id in ~/.atropos/config.yaml → alerts.

No alerts run yet.

What triggers

  • ⚠ Disk usage > 80%
  • ❌ Any doctor check fails
  • 🔌 Router ping fails / slow
  • 🧩 Patch verify fails
  • 🔄 Update available
Rate-limited to 1 per 10 min per event.
